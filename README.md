## 📖 Tentang Proyek

**AA_NT** adalah sebuah platform web yang didedikasikan untuk melestarikan dan mempromosikan seni budaya Nusantara. Platform ini hadir sebagai jembatan antara seniman budaya Indonesia dengan penikmat seni di seluruh penjuru negeri.

Melalui platform ini, pengguna dapat:
- 🎟️ **Membeli tiket** pertunjukan seni budaya tradisional
- 🎬 **Menonton video** tarian-tarian khas Indonesia
- 🖼️ **Menjelajahi galeri** karya seni budaya Nusantara
- 🛒 **Mendukung seniman** dengan membeli karya mereka secara langsung

> *"Salah satu cara untuk mengapresiasi dan melestarikan seni budaya adalah dengan membeli karya seniman — kita ikut serta dalam melestarikan budaya Indonesia."*

## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🎟️ **Tiket Festival** | Beli tiket untuk event budaya seperti Konser & Festival Budaya, Semarak Budaya, Festival Tari, dan Gau Maraja |
| 🎬 **Video Tari** | Tonton video tarian tradisional: Tari Jaipong, Tari Remo, Tari Piring, Tari Kecak, dan lainnya |
| 🖼️ **Galeri** | Jelajahi galeri foto dan karya seni budaya Nusantara |
| 🛒 **Keranjang Belanja** | Sistem keranjang belanja yang mudah digunakan |
| 💳 **Pembayaran** | Proses pembayaran yang aman dan konfirmasi otomatis |
| 👤 **Profil Pengguna** | Kelola akun dan riwayat pembelian Anda |
| 🔐 **Autentikasi** | Sistem login dan registrasi pengguna |

## 🗺️ Konten Budaya

Platform ini menampilkan kekayaan seni budaya dari berbagai daerah di Indonesia:

### 🕺 Tarian Tradisional
- **Tari Jaipong** — Tarian tradisional dari Jawa Barat
- **Tari Remo** — Tarian penyambutan tamu dari Jawa Timur
- **Tari Piring** — Tarian Minangkabau dengan atraksi piring
- **Tari Kecak** — Pertunjukan dramatari seni khas Bali
- **Tari Saman** — Tarian massal dari Aceh

### 🎪 Event & Festival
- **Konser & Festival Budaya**
- **Semarak Budaya**
- **Festival Tari**
- **Gau Maraja**

## 🚀 Cara Menjalankan

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/nasrulaminmuis/AA_NT.git
   ```

2. **Masuk ke folder proyek:**
   ```bash
   cd AA_NT
   ```

3. **Buka di browser:**
   - Buka file `index.html` langsung di browser, **atau**
   - Gunakan ekstensi **Live Server** di VS Code untuk pengalaman terbaik

> 💡 **Tips:** Gunakan ekstensi [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) di Visual Studio Code agar perubahan langsung terlihat di browser.
